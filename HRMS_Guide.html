🗄️ SQL Database

The database schema is stored in hrms.sql at the project root. It contains 4 tables:

📊 Database Tables

  • Users: Login credentials (username, password)
  • Department: Company departments (HR, IT, Finance, etc.)
  • Position: Job positions (Manager, Developer, Accountant, etc.)
  • Employee: Employee records linked to Department and Position

⚙️ How to Load Database

Open phpMyAdmin (via XAMPP Control Panel) and import hrms.sql:

Steps
1. Open XAMPP Control Panel
2. Click "Admin" next to MySQL
3. Go to "Import" tab
4. Select hrms.sql file
5. Click "Go"
✅ After import, you should see an "HRMS" database with 4 tables in phpMyAdmin.

Install backend dependencies and configure environment:

Terminal

cd HRMS/backend

# 2. Install all required packages

📄 File: backend/.env

Create a .env file in the backend folder for database configuration:

.env

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=HRMS

⚠️ If your MySQL has a password, add it after DB_PASSWORD=. For XAMPP, leave blank.

JSON
{

    "start": "node server.js",

  }
}

🖥️ File: backend/server.js

This is the main Express server. Create server.js in the backend folder:

Key features:

  • Express server with CORS enabled
  • MySQL database connection
  • JWT authentication middleware
  • RESTful API routes for employees, departments, positions
JavaScript
const express = require('express');
const mysql = require('mysql2');
const cors = require('cors');
const jwt = require('jsonwebtoken');
require('dotenv').config();

const app = express();
app.use(cors());
app.use(express.json());

// MySQL Connection
const db = mysql.createConnection({
    host: process.env.DB_HOST,
    user: process.env.DB_USER,
    password: process.env.DB_PASSWORD,
    database: process.env.DB_NAME
});

db.connect((err) => {
    if (err) console.error('DB error', err);
    else console.log('✅ DB connected');
});

// Start server
app.listen(process.env.PORT, () => {
    console.log(`🚀 Server on port ${process.env.PORT}`);
});

🔗 File: frontend/src/api/axiosConfig.js

This file configures the HTTP client for API calls. Create it in the src/api/ folder:

JavaScript
import axios from 'axios';

// Base URL of backend server
const api = axios.create({
    baseURL: 'http://localhost:5000'
});

// Add JWT token to every request
api.interceptors.request.use((config) => {
    const token = localStorage.getItem('token');
    if (token) {
        config.headers.Authorization = `Bearer ${token}`;
    }
    return config;
});

export default api;
💡 This sets the backend URL and automatically adds authentication token to all requests.

🗺️ File: frontend/src/App.jsx

This is the main router that handles page navigation. It imports all components and sets up routes:

JSX
import { BrowserRouter, Routes, Route, Navigate } from 'react-router-dom';
import Login from './components/Login';
import EmployeeList from './components/EmployeeList';
// ... import other components

export default function App() {
    return (
        <BrowserRouter>
            <Routes>
                <Route path="/login" element={<Login />} />
                <Route path="/employees" element={<EmployeeList />} />
            </Routes>
        </BrowserRouter>
    );
}

📦 Components Overview

All React components are in frontend/src/components/:

🔒 Login.jsx

Login page. Collects username/password, calls /api/login, stores token in localStorage.

👥 EmployeeList.jsx

Displays table of all employees from /api/employees. Has buttons to add, edit, delete employees. Shows status badge (active, on leave, etc.)

✏️ EmployeeForm.jsx

Form to add or edit an employee. Auto-fetches departments and positions for dropdowns. Posts to /api/employees or /api/employees/:id.

🏢 DepartmentList.jsx

List of departments. Add/edit/delete departments. Calls /api/departments.

💼 PositionList.jsx

List of job positions. Add/edit/delete positions. Calls /api/positions.

📊 StatusReport.jsx

Report showing employees on leave grouped by department. Calls /api/report/on-leave.

🚀 Deployment

When ready to deploy to production:

Frontend Build

Terminal
cd HRMS/frontend
npm run build

This creates a dist/ folder with optimized static files. Upload this to a hosting service like Netlify, Vercel, or AWS S3.

Backend Deployment

Deploy the backend folder to a Node.js hosting service (Render, Railway, DigitalOcean, Heroku, etc.). Set environment variables on the host:

  • PORT (usually auto-set by host)
  • DB_HOST (your production database host)
  • DB_USER, DB_PASSWORD, DB_NAME
  • JWT_SECRET (strong random key)
⚠️ Never commit .env file to GitHub. Use gitignore or environment variables on the host.
